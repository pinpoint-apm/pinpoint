# Fixtures of other OTLP metric sources

Raw `ExportMetricsServiceRequest` bodies (OTLP/HTTP protobuf, no gzip) captured on 2026-11-03 from
probe applications on Windows 11, read by `OtherSourceFixtureTest`. Every probe served `GET /ok`,
`/sleep` (120 ms) and `/throw` every 5 s, so the HTTP server duration has observations between two
exports. All exports are CUMULATIVE (the SDK defaults).

**Scrubbed**: the resource keeps only `service.*`, `pinpoint.agentId`, `telemetry.sdk.*`,
`telemetry.distro.*`, `process.runtime.*` and `os.type` (host name, user, command line and paths
removed); the Python files also leave out the `system_metrics` instrumentation scope (it names the
local network and disk devices). The metrics themselves are as sent.
